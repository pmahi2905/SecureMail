# SecureMail 🔒

I built this because my family members kept getting suspicious emails 
and had no way to tell if they were real or not. So I made something 
that does it for them.

## What it does
You paste in an email you received, and it tells you whether it looks 
safe or like a phishing attempt. It also keeps a history of everything 
you've scanned.

## Why I made this
Phishing emails are genuinely dangerous and most people can't spot them. 
I wanted to build something useful, not just another to-do app. It also 
pushed me to think about how to actually detect suspicious patterns in 
text using code.

## What I used
- Python — for the detection logic and backend
- Flask — to build the website
- SQLite — to store scan history
- HTML & CSS — I went with a dark mode design
- GitHub — for version control

## What I learned
- How to write logic that finds red flags in text
- How Flask routes and templates work together
- How to store and retrieve data with SQLite
- That dark mode CSS is harder than it looks
